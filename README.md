# Kendet

Kendet is a Windows app for making structured summaries your own way, faster: read
your PDF beside your summary, organise ideas with comparisons, breakdowns,
equations and images, and export to PDF.

**This is a beta.** Windows only, for now.

## Download

**[Download Kendet for Windows](https://github.com/kendet-app/releases/releases/latest/download/Kendet-setup.exe)**

It installs for your user only — no administrator prompt. After that, Kendet tells
you when a newer version is ready and updates when you say so.

### Windows will warn you the first time

The installer is not code-signed yet, so Windows SmartScreen shows a blue
"Windows protected your PC" box:

1. Click **More info**.
2. Click **Run anyway**.

<!-- screenshot of both SmartScreen steps here -->

You only do this once, for the first install. Updates inside the app do not repeat it.
